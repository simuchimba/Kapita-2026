              KAPITA VERCEL DEPLOYMENT COMMANDS
═══════════════════════════════════════════════════════════

📋 COPY AND PASTE THESE COMMANDS IN ORDER:

─────────────────────────────────────────────────────────────
STEP 1: LOGIN TO VERCEL (One Time Only)
─────────────────────────────────────────────────────────────

npx vercel login

→ A browser will open. Login and return to terminal.


─────────────────────────────────────────────────────────────
STEP 2: DEPLOY BACKEND
─────────────────────────────────────────────────────────────

cd /Users/lbs/kapita/backend
npx vercel --prod

→ Answer prompts:
  - Set up and deploy? Y
  - Link to existing project? N
  - Project name? kapita-backend
  - Modify settings? N

→ SAVE THE BACKEND URL YOU GET!


─────────────────────────────────────────────────────────────
STEP 3: DEPLOY FRONTEND
─────────────────────────────────────────────────────────────

cd /Users/lbs/kapita/frontend
npx vercel --prod

→ Answer prompts:
  - Set up and deploy? Y
  - Link to existing project? N
  - Project name? kapita-frontend
  - Modify settings? N

→ SAVE THE FRONTEND URL YOU GET!


─────────────────────────────────────────────────────────────
STEP 4: SET ENVIRONMENT VARIABLES
─────────────────────────────────────────────────────────────

Go to: https://vercel.com/dashboard

FOR BACKEND PROJECT:
  Settings → Environment Variables → Add:
  
  SECRET_KEY = django-insecure-prod-key-12345
  DEBUG = False
  ALLOWED_HOSTS = .vercel.app
  CORS_ALLOWED_ORIGINS = https://your-frontend.vercel.app
  
  Then: Deployments → Redeploy

FOR FRONTEND PROJECT:
  Settings → Environment Variables → Add:
  
  VITE_API_URL = https://your-backend.vercel.app/api
  
  Then: Deployments → Redeploy


─────────────────────────────────────────────────────────────
STEP 5: TEST
─────────────────────────────────────────────────────────────

Open: https://your-frontend.vercel.app

Test:
  ✓ Register new account
  ✓ Login
  ✓ View dashboard
