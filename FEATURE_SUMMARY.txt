┌──────────────────────────────────────────────────────────────────────┐
│ 💻 HOW TO USE                                                        │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│ 1️⃣  CREATE A PROMOTION                                              │
│    • Go to: http://127.0.0.1:3000/app/promotions                   │
│    • Click "New Promotion"                                         │
│    • Fill in: Name, Type, Value, Dates                             │
│    • Choose: All products or specific ones                         │
│    • Click "Create Promotion"                                      │
│                                                                      │
│ 2️⃣  APPLY TO A SALE (Auto)                                          │
│    • Go to: http://127.0.0.1:3000/app/sales                        │
│    • Click "New Sale"                                              │
│    • Select product & quantity                                     │
│    • Choose promotion from dropdown                                │
│    • See automatic discount applied!                               │
│                                                                      │
│ 3️⃣  MANUAL DISCOUNT                                                 │
│    • Go to: Sales → New Sale                                       │
│    • Select product & quantity                                     │
│    • Choose "Percentage Off" or "Fixed Amount"                     │
│    • Enter value & optional reason                                 │
│    • See discount in price breakdown                               │
│                                                                      │
